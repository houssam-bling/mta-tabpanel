# Requirements & Dependencies
# متطلبات المشروع

## Frontend Dependencies
- HTML5
- CSS3
- JavaScript (ES6+)
- No external libraries required (Vanilla JS)

## Browser Support
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## Server Requirements
- MTA: San Andreas v1.5+
- Node.js 14+ (optional, for API server)
- PHP 7.4+ (if using PHP backend)
- MySQL 5.7+ (optional, for data storage)

```bash
npm install
```
